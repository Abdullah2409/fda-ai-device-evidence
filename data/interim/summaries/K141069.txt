Imbio CT Lung Density Analysis Software
Indications for Use (Describe)
The Imbio CT Lung Density Analysis Software provides reproducible CT values for pulmonary tissue, which is essential
for providing quantitative support for diagnosis and follow up examinations. The Imbio CT Lung Density Analysis
Software can be used to support the physician in the diagnosis and documentation of pulmonary tissue images (e.g.,
abnormalities) from CT thoracic datasets. Three-D segmentation and isolation of sub-compartments, volumetric analysis,
density evaluations and reporting tools are provided.
